# Documentation

Use this index to find the current guide for your task. Milestone reports are
historical implementation records; the other documents describe the current
product.

## For Users

- [User Guide](USER_GUIDE.md): start the app, create a plan, manage pantry
  stock, use Today and Week, shop, protect local data, and troubleshoot.
- [Local Setup](../LOCAL_SETUP.md): concise installation and startup commands.
- [Sample Meal Plans](SAMPLE_MEAL_PLANS.md): example Andhra Telugu weeks.
- [Local-First Privacy Notes](../LOCAL_FIRST.md): what stays local and what can
  use the network.
- [Security Policy](../SECURITY.md): secrets, local data, and reporting issues.

## For Contributors

- [Architecture](../ARCHITECTURE.md): system components, data flow, persistence,
  resilience, and safety boundaries.
- [Repository Structure](REPOSITORY_STRUCTURE.md): directory ownership and file
  placement rules.
- [Backend Guide](../backend/README.md): API, request shape, and backend checks.
- [Planner Pipeline](PLANNER_PIPELINE.md): candidate generation, validation,
  ranking, fallback, and persistence.
- [Pantry V2](PANTRY_V2.md): inventory and transaction behavior.
- [Ingredient Ontology](INGREDIENT_ONTOLOGY.md): identity and unit rules.
- [Offline Evaluations](EVALS.md): deterministic planning quality gates.

## Product and Delivery Records

- [Product Reframe](LOCAL_FIRST_PRODUCT_REFRAME.md): privacy-by-design product
  rationale.
- [Phase Completion](PHASE_COMPLETION.md): final Phase 1–30 implementation map.
- `MILESTONE_1.md` through `MILESTONE_9.md`: historical milestone baselines,
